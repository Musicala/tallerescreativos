# Musicala · Talleres Creativos

Micrositio estático y responsive para explicar los talleres creativos de Musicala a empresas, instituciones y grupos.

## Archivos
- `index.html`
- `styles.css`
- `app.js`

## Uso local
Abre `index.html` en el navegador.

## Publicación
Puedes subir estos tres archivos directamente a:
- GitHub Pages
- Firebase Hosting
- Netlify
- Vercel

## Incluye
- Presentación de talleres
- Disciplinas: Música, Danza, Artes Plásticas y Mix Artístico
- Planes y precios:
  - 1H: $114.000
  - 4H: $408.000
  - 8H: $772.000
  - 12H: $1.098.000
  - 24H: $2.070.000
- Flujo visual “cómo funciona”
- Mini configurador de propuesta
- Botón para copiar un resumen listo para enviar a Musicala
- Diseño responsive para celular y computador

## Nota
El sitio no inventa costos adicionales. Para grupos grandes, sedes externas o requerimientos especiales, se deja indicado que Musicala confirma la propuesta final según logística.
